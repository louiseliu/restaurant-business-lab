## 本地复建

需要已安装且兼容的官方 Data 插件和 Node 绝对路径，无需联网查源或安装依赖。

`python build_standalone.py OUTPUT_DIR NOTE_PATH FROZEN_JSON NODE DATA_PLUGIN_ROOT`

把本目录放在 `OUTPUT_DIR/source/`，NOTE_PATH旁须有同版sources.md。脚本先核验冻结状态与两稿哈希，再产生完整文章、图文与reviewed queries。首次准备通过官方report preparer建立新报告身份。已有输出只有在原文、图文、query、阅读器和样式完全一致时才无写入复用，否则在写入前拒绝，保留用户改动。本脚本不用于多篇门户。

官方 `build --separate-data` 后执行 `export-offline`，生成 `.data-app-offline/exports/order-alert.html`，再逐字复制到 `OUTPUT_DIR/order-alert.html`。不手改编译后HTML。同一准备身份与冻结输入的复建应字节一致，全新准备则建立新的报告身份。
