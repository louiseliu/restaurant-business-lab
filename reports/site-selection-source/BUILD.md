## 本地复建

需要兼容的官方 Data 插件与 Node 绝对路径，无需联网查源或安装依赖。

`python build_standalone.py OUTPUT_DIR NOTE_PATH FROZEN_JSON NODE DATA_PLUGIN_ROOT`

把本目录置于 `OUTPUT_DIR/source/`。NOTE_PATH 邻接同版 sources.md、calculations.py 与 calculation-results.json。脚本验证真实首提与时间格式、编辑冻结和回读状态、全文与来源哈希，然后生成图文和查询。

首次运行调用官方 report preparer。已有单篇只有在原文、图文、查询、阅读器与样式完全相同时才无写入复用；不一致时写入前拒绝，避免覆盖用户改动。安装器不得用于门户。

官方 `build --separate-data` 后，调用 `export-offline` 导出 `.data-app-offline/exports/siteselection.html`，逐字复制到 `OUTPUT_DIR/siteselection.html`。不编辑编译 HTML。相同准备身份复建字节一致；全新准备会生成新报告ID。
