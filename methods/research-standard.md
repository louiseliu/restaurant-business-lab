# 研究规范

## 证据与结论

- 每项重要事实保留直接来源 URL、发布主体、发布日期、数据期间、单位和统计范围。无法核对发布时间时标记未知。
- 优先原始统计、企业公告、监管披露和原始研究。企业自报数据要保留自报属性，不能把宣传当作独立核验。
- 区分总部、直营店、加盟商、终端交易与会计收入口径；警惕净额/总额、期末数/平均数、同店/全网混用。
- 标明事实、计算、经营假设和建议。计算应保留可运行代码、输入和结果；模拟数值不得冒充真实门店数据。
- 记录最有力的反例、替代解释、结论失效条件和最省成本的验证动作。

## Pro 协作

- 发送前核对目标项目、实际 Pro 模型与资料分享范围。
- 发送后记录状态；超时先检查原会话，避免重复提交。
- 回答中的重要事实另行查证；将新证据、失败结果和计算反馈给同一问题的相关会话。
- 未访问、未确认模型、未收到回复，均不得记作已完成 Pro 研究。
- 私有项目定位和登录资料不进入公开仓库；只有获准公开且不含敏感资料的会话摘要或链接才可发布。

## 发布与验收

- 发布前检查凭据、私人数据、内部路径、未经允许的原文及不实成功声明。
- GitHub 操作须核实远端提交与目标分支，不把本地文件或创建请求当作成功提交。
- 研究建议不是自动经营决策。不得自行购买服务、投入资金、访谈外部人员或改变真实经营系统。
- 定时或持续运行依赖宿主实际支持和授权；Skill 文件本身不是后台服务。
