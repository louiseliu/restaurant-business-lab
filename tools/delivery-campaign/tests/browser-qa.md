# 实际浏览器验收记录

日期：2026-10-29。环境：现成 Cloud Chrome，由 CUA 操作；Sites managed 本地静态预览。未发布站点。

## 已实际验证

- 桌面：顶部“演示/非实测”与三项限制完整可见；默认结果 −1,200.00 元、持平约 50%。
- α=100%：+6,000.00 元，替代订单为 0，情景表与说明同步。
- N=−1：显示错误、隐藏结果和图表、禁用记录下载，没有保留旧计算结果误导。
- α=101%：明确阻断超范围输入；恢复 40% 后重新计算。
- N=0、F=2000：−2,000.00 元，“没有活动订单”，没有除零阈值。
- cᵦ=0：显示标准阈值不适用；cᵦ=−4：显示曲线方向反转说明。
- 单均辅助：默认 8/12 元；活动佣金未扣项改为 3 后，辅助贡献为 5 元；点击应用后主结果为 −4,200 元。
- 恢复演示：五个主输入与辅助表恢复，标签恢复“非真实门店”。
- 本地 JSON 下载完成；读取下载内容核对 status=演示数据，delta≈−1200，threshold=0.5。
- 390px iframe（实际内容宽 375px，浏览器滚动条占宽）：`sandbox="allow-scripts"`，不含 allow-same-origin；运行与改数成功。
- iframe 中导出/打印按钮隐藏；提示通过外层下载独立 HTML。α100% 重算为 +6,000 元。
- 窄屏根 body：scrollWidth=clientWidth=375；展开成本表后仍相等。宽成本表只在内部横向滚动。
- 发现窄屏固定 SVG viewBox 导致标签缩小，已改为按实际宽度重绘；重新截图核对 viewBox=0 0 313 270，坐标/标签可读。
- 浏览器日志出现 chrome-extension 的 metadata 错误，不是页面脚本来源；未见本页脚本报错。
