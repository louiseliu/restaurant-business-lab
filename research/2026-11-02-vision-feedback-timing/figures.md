# 配图方案：反馈时间不是识别速度

## 图1：两条流程，改变的是不同结果

建议浅色背景，双轨泳道。全部为研究院示意，不画实际耗时、比例或品牌现场。

A. 当份拦截路径（同步）
制作 → 既有现场检查 → AI判断及例外处置 → 交付
强调框：有机会改变“这一份”，也增加等待与处置依赖。
注意：仅是概念对照，不声称所有同步产品按此顺序部署。

B. 复盘改进路径（异步）
制作 → 既有现场检查 → 交付
旁路：采集/分析 → 负责人复盘 → 后续班次改进
强调框：不让生产等待分析；不能追回已经交付的差错。

底注：研究院机制示意，不是遇见小面完整系统图；两条路径均不得替代法定或门店安全措施。

## 图2：采购验收的两个终点

两张等宽卡，不作无根据的定量排序。
当份任务：发现时是否仍可纠正 → 是否完成纠正 → 是否影响交付等待。
后续任务：偏差是否可解释 → 是否落实改进 → 同类偏差是否仍复发。
共同底栏：保留原流程基线；检查未报警样本；记录新增处置与维护成本。

不要画准确率雷达图、300元总成本、0.3秒端到端时延、覆盖比例、全量检测、报警SLA。
