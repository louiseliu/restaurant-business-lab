# 模拟周报｜订单增长，所列成本后贡献却下降

> 模拟数据；本包AI辅助编制并经计算回查，非门店实测；没有测得省时/准确率提升。
>
> 编制方式：本次 AI 助手读取实际执行的本地 Python 输出后起草，再通过数值断言和独立 SQL 复算回查。没有调用外部模型 API；没有声称使用 GPT Pro、WorkBuddy 或现场模型工具。下列事实仅是“此模拟数据集内的计算事实”。

报告期 W2：2026-10-19—10-25；比较期 W1：2026-10-12—10-18。范围：虚构溪桥店、长青店；堂食与外卖；同店完整周。金额人民币元。

## 一、计算事实：多了订单和净收入，贡献没有跟上

- **履约订单 1,694 单，较前周 1,533 单增加 161 单（+10.50%）。商家净收入 63,945.52 元，增加 1,966.05 元（+3.17%）。** [C01/C02：`results/analysis.json → weekly`；逐行来源见 `source_record_ids` 与 `raw_csv_lines`。]
- **所列成本后贡献 30,688.74 元，较 32,854.64 元减少 2,165.90 元（-6.59%）。贡献率 47.99%，下降 5.02 个百分点。** 这里尚未扣人工、租金、税费、折旧等，不是完整净利润。[C03/C04：`weekly`、`comparisons`。]
- 每单净收入由 40.43 元降至 37.75 元，每单贡献由 21.43 元降至 18.12 元。订单增幅高于金额增幅，不能据订单增长判断赚钱增加。[C05/C06：`comparisons`；先合计再除同群履约订单。]

## 二、计算事实：贡献减少主要落在外卖，但这不是因果归因

外卖订单从 637 单增至 805 单（+26.37%）；净收入从 21,997.39 元增至 24,296.08 元，所列成本后贡献却从 7,093.24 元降至 5,142.25 元，每单贡献从 11.14 元降至 6.39 元。[C07：`channel_weekly`。]

全店贡献变动 -2,165.90 元 = 堂食 -214.91 元 + 外卖 -1,950.99 元。外卖这一下降约占总降幅 90.08%，这是可相加分组的**算术分解，不是外卖、优惠或广告造成亏损的因果效应**。[C08：`channel_delta_bridge`。]

外卖商家优惠率从约 9.00% 升至 17.00%；广告消耗从 840.00 元升至 1,680.00 元；每单净收入从 34.53 元降至 30.18 元。平台优惠由平台承担，不应再扣一遍商家贡献。优惠、商品组合、标价、订单量及成本同时变化，不能将前后差直接叫作“活动效果”。[C09：`channel_weekly`。]


从金额勾稽看，全店净收入增加 1,966.05 元，所列成本增加 4,131.95 元，净差为贡献减少 2,165.90 元。成本增量分为食材 2,291.26 元、包装 301.00 元、平台服务 183.90 元、支付 11.79 元、商家配送 504.00 元、广告 840.00 元。这是实际输出的**会计式差额桥**，不能据此识别每项成本变化的经营原因。[`cost_delta_bridge`。]

## 三、可能解释：需要真实取数才能判别

- **假设 A：** 商家优惠更深、广告和履约成本增加，可能压低每单贡献。但本包生成器有意同时改变这些参数，不是实际经营观测，更没有随机或可比对照。
- **替代解释：** 商品组合/标价变化、自然需求波动、堂食转外卖、退款归属或费用重复入账也可能影响结果。当前没有 SKU、顾客、流量、天气、券活动或账单流水，不能排除。
- **反例/失效条件：** 若平台补贴被追回、同单跨期退款漏记，或固定人工与产能显著变化，当前贡献口径仍不足以决定是否扩大活动、加人、关店或开店。
