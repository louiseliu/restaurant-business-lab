# 经营数据 → AI 周报：离线可执行实战包

**模拟数据；本包AI辅助编制并经计算回查，非门店实测；没有测得省时/准确率提升。**

这是教学用完整样板：两家虚构门店，2026-10-12 至 10-25 共 14 日，堂食/外卖两渠道。不是对任何真实门店、平台或品牌的诊断。不调用外部模型 API、不上传数据、不联系客户、不改经营系统；本包未发布为 Site。

## 先看成品

- `case-demo.html`：自包含 HTML，解压后可离线阅读；两幅数据图、完整 AI 辅助周报、记录筛选与单条金额追溯。**展示预计算结果，不在浏览器执行 Python，不上传 CSV，不调用模型。**
- `docs/weekly_report.md`：本次 AI 助手读取实际 Python 结果后起草的报告，不是空白模板。
- `docs/data_dictionary.md`：粒度、退款归属、优惠承担、成本边界与金额桥。
- `docs/prompts.md`、`docs/review_checklist.md`：可复制提示词、人工审核及放行模板；未安装为 Skill。

原始 CSV 是日 × 店 × 渠道汇总，**没有逐笔订单 ID**。追溯止于原记录与 CSV 行号，不伪装成订单明细。

## 在本地复跑（Python 3.10+，仅标准库）

在包根目录执行：

```sh
python src/generate_sample.py
python src/analyze.py
python src/test_analysis.py
```

或者运行 `python src/run_all.py`，它依次执行上面三步；没有网络请求或第三方依赖安装。

- 第一步按固定公式重新生成**模拟** CSV，并写输入哈希和故障清单。
- 第二步清洗和校验，输出 `results/`。缺值、未知渠道、冲突重复、缺日期/门店/渠道或金额勾稽失败会报错停止；不填零、不插值、不让 AI 猜测。
- 第三步运行 16 项测试，包含从原 CSV 独立 SQLite 复算、错误输入拒绝和 107 个冻结数值预期。测试通过只说明本样本数值/规则满足检查，**不是准确率测量，也不是人工签字**。
- `docs/claims_manifest.json` 是当前草稿的冻结数值契约；改输入后不要自动把 expected 改成新数来“过测试”。应先调查、重新编稿，再由人检查受影响结论。

可以把 `--input <CSV> --out <目录>` 传给 `src/analyze.py` 测试同口径文件，但当前校验有意锁定两店、14 日、两个渠道。真实门店数据应先授权、核字段和退款成熟期，再改造规则；**不能直接声称本样板适配任意导出。** 不要把真实敏感数据粘贴到未授权的模型或上传此演示页面。

## 本次真实执行结果

- 原始 57 行 → 合格 56 行；删除 1 条完全重复，规范 3 处空白和 1 个明示渠道别名。
- 78 项金额及分店/渠道汇总勾稽通过；另有 16 项测试及独立 SQL 复算。代码与日志均保留。
- W1：1,533 单；商家净收入 61,979.47 元；所列成本后贡献 32,854.64 元。
- W2：1,694 单；商家净收入 63,945.52 元；所列成本后贡献 30,688.74 元。
- **商家净收入不是银行到账/会计营收；所列成本后贡献不是完整净利润。** 前后周变化不是活动、广告或 AI 带来的因果效果。

金额存“分”整数；展示才转“元”。平台优惠由等额平台补贴补足且模拟无追回；顾客退款归原履约日，模拟退款窗口截至 2026-10-28。未计人工、租金、水电、税费、折旧等。

## AI 到底做了哪一部分

当前 AI 助手制定分析口径、编写并实际执行本地代码、读取结果、起草周报并回查数字。Python 仅执行确定性计算；**没有外部模型 API 调用，没有冒称 GPT Pro、WorkBuddy 或现场模型工具实测**。复跑代码不会重新生成 AI 文稿。`src/prepare_snapshot.py` 仅把已审核文稿与结果打包到展示数据；不代替文稿审核。

尚未进行：真实门店核账、门店负责人签字、人工基准对照、模型准确率评估、节时测量、因果试验。不能将检查数量转换成准确率，也不能捏造人工耗时或节省成本。

## 文件入口

|目录/文件|用途|
|---|---|
|data/simulated_daily_raw.csv|含故意注入导出问题的完整模拟输入|
|data/generation_manifest.json|固定生成说明、输入哈希、注入故障及行号|
|results/cleaned_daily.csv|清洗后 56 行及计算字段/原行号|
|results/analysis.json|完整聚合、前后周比较、渠道/成本差额桥、敏感性情景及原记录追溯|
|results/*_summary.csv、*weekly.csv|可用表格工具直接打开的汇总|
|results/quality_report.json|真实清洗动作与 78 项勾稽结果|
|src/*.py|可运行生成、分析、测试、快照脚本|
|qa/independent_recompute.sql/json|独立原始行 SQL 复算方法和结果|
|qa/analysis-run.log、test-run.log|本次实际执行日志，不是截图填充|
|docs/claims_manifest.json|草稿/展示数值回查的冻结预期|
|docs/build.md|HTML 源码与构建说明|
|qa/verification.md|验证范围、渲染核查状态及限制|
|release-manifest.json|公开安全 allowlist、每个文件的 SHA-256|

原始表与结果表用 UTF-8 BOM，便于中文表格软件打开。HTML 可单文件分发；其余文件一起保留才能完整复算。包内没有账号凭据、客户资料或私人项目链接。不要将包含环境配置的整个作者项目公开。
